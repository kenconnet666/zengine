# P8A Native UI Scale Status

Status: accepted on 2026-08-27 for the current Win11 x64 + RTX 3050 Laptop GPU validation target.

## Implemented

- `WindowDpi` in the portable window contract.
- Win32 Per-Monitor DPI Aware V2 initialization.
- `GetDpiForWindow`, DPI-aware client sizing and `WM_DPICHANGED` suggested-bounds handling.
- `UiScaleContext` with logical size, physical size, DPI and scale.
- Logical-DIP layout with a single physical-pixel conversion in `UiPaintCompiler`.
- Edge snapping for boxes and borders plus integer text-baseline snapping.
- Explicit sRGB-to-linear conversion and premultiplied-alpha Vulkan blending.
- Glyph rasterizer request/hit/miss telemetry.
- UI paint, box, glyph, instance, draw, upload and compile-time telemetry.
- Native UiLab, Editor Lab and Game Slice integration.
- Repeatable 100%, 125%, 150% and 200% capture matrix with SHA-256 JSON manifest.

## Real machine evidence

The current Windows desktop reports DPI 144 (150%). Native UiLab maps 960x640 DIPs to 1440x960 physical pixels. The Editor Lab maps 1280x760 DIPs to 1920x1140 physical pixels and reports:

- 57 UI nodes;
- 52 paint commands;
- 40,445 instances and draw calls;
- 652 glyph-cache hits and 160 misses;
- zero Vulkan validation errors.

The instance count grows with glyph pixel coverage even though the logical content is unchanged. This is direct evidence that the row-quad baseline must be replaced rather than micro-optimized.

## Deliberate boundary

P8A fixes scale, snapping, color and measurement. It does not claim the text pipeline is visually complete. Native text still uses GDI rune rasterization and horizontal coverage quads, has no shaping/fallback metrics, and remains the dominant draw-count and edge-quality problem.

## Next gate

P8B must introduce glyph-id runs, real font metrics, shaping and Windows DirectWrite fallback behind portable contracts. P8C then uploads the resulting grayscale coverage into a sampled Vulkan atlas and batches glyph instances. The P8C acceptance targets remain fewer than 200 UiLab instances, fewer than 1,500 Editor instances and at most eight steady Editor UI draws.
